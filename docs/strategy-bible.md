## 一、当前生产策略 (三腿组合, 定稿 2026-11-24)

### 打板腿 (主力, K=2槽)
- 信号: 昨首板(昨涨停且前日未涨停且昨开<昨收) + 今日回调-5%~+3% + 缩量(量<5日均*0.8) + 温和(-3%~+3%) + 评分>=12
- 评分 = 缩量*4 + 温和*4 + 情绪(涨停家数5日均>=30记4/>=15记3/>=8记2/否则1) + 热度(当日涨停>=60记3/>=30记2/否则1)
- 执行: 次日开盘买 → 挂当日开盘价+4%冲高卖(分钟close触及成交) / 止损-2%(收盘判) / 最长8日 / 涨停骑乘 / 炸板收盘<5%必走
- 胜率58% / 单腿年化+40.7% / 回撤-4.7% (T+1合规真约束)

### 反转腿 (K=2槽)
- 15日跌-30% + 量比1.5 + 阳线 → 次日-3%限价买 → 骑反弹到收盘(无止盈) / 止损-8% / 5日
- 注意: -40%阈值在过滤后只触发退市股, 已回滚-30%

### 低波腿 (K=5槽)
- 月度轮换: 20日波动率最低Top5 + 日均额>2000万 → 次日开盘买 → 持有30日

### 日内alpha栈 (持仓次日及以后)

### 组合成绩
- 三腿各1/3: **年化+40.3% / 回撤-2.0%** (2023正常年+24.6%, 2025冷清年+3.0%)

## 三、挣钱逻辑 (核心哲学)

1. **胜率高≠赚钱**: 70%胜率配置+26% vs 58%胜率配置+40.7% — 盈亏比2:1(赚4亏2)才是钱
2. 事件后回调(打板) + 低波溢价(低波) + 恐慌错杀(反转) = 三个独立收益源, 月相关<0.4
3. 冷清市纪律: 信号少时空仓>硬做 (2025/2026 +3%是冷市正常水平)
4. 冷市切换: 涨停家数5日均<50 → 低波腿拿2/3资金 (回撤-1.0%)
5. 止损看收盘不看盘中低点 (避免下影线假止损, 胜率+8pp)
